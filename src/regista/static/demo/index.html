For judges · Inside the Game hackathon

Regista directs every touch.

Regista watches a football match and cuts every moment each player is on the ball, plus every replay and highlight they appear in.

Agents on Microsoft Agent Framework label and explain each moment and write match recaps; Microsoft Foundry answers questions and can write the recap.

It also runs a synthetic catalogue of footage uploaded below the professional level, where scouts compare players within their own level and every number opens the moments behind it.

12 short steps across the live app, about five minutes. It only reads: nothing you click changes Regista.

    Synthetic data, by design

    The hackathon asks for synthetic, football-realistic data, so Regista generates its own: a league season and a catalogue of uploaded matches, with every player moving at 10 Hz within their own pace. Every player, club and competition is invented; countries and levels are labels. The footage is Regista's own broadcast-style render. There are no real players, no real footage and no Premier League data here.

    Good to know

    • Everything is open to read. Uploads, reviews and other changes need the operator's key, so nothing you click here changes Regista.
    • Ask Microsoft Foundry is open too, with a limit of a few questions a minute per visitor. Data Search answers instantly with Regista's own rules.
    • A clip nobody has played since the last deploy is rendered on its first view, which takes a few seconds.
    • The Studio, the operator's dashboard, opens with the view-only key given in the submission.
