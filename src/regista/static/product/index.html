How it works

Two layers

Vision layer private, runs offline

Video in, events out. It finds the cuts between the main camera and replays, follows every player by kit number, team colours and tracking, decides who has the ball, and spots passes, shots, take-ons and nutmegs. The footage never leaves the machine it runs on.

Intelligence layer this app

Events in; clips, labels and answers out. It cuts every moment a player is on the ball in the main camera, plus every replay and highlight they appear in, labels each one, scores how worth watching it is, and finds it when you ask.

Between them sits one list of match events in a published format. The demo matches come from Regista's own match generator, which writes the same list, so no real footage or data is needed.

The agent workflow

A Microsoft Agent Framework workflow: each agent has one job and passes what it found to the next. An agent that fails tries again, and anything it still cannot handle is set aside and recorded, so one bad record never stops the whole match.

  1. Ingest reads the event stream and indexes it.
  2. Validator checks every event is complete and well formed.Possession finds each player's time on the ball. in parallel, then joined
  3. Clip cuts on-ball moments, replays and highlights.
  4. Label names each moment, scores it and says why.
  5. Review asks a person about the labels it is unsure of.
  6. Persist stores clips and labels.
  7. Indexer adds them to the search index. only where Azure AI Search is configured
  8. Librarian answers questions over the labelled clips.

How real is the data?

The three-minute demo matches are packed on purpose, so a short clip reel has goals, nutmegs and replays in it; their numbers sit above a real match's. With its realistic setting, over eight 30-minute matches, the generator sits inside Premier League ranges per 90 minutes on all 13 measures Regista checks (passes, shots, goals, tackles, nutmegs and more).
