How it works

Two layers

Vision layer private, runs offline

Video in, events out. It finds the cuts between the main camera and replays, follows every player by kit number, team colours and tracking, decides who has the ball, and spots passes, shots, take-ons and nutmegs. The footage never leaves the machine it runs on.

Intelligence layer this app

Events in; clips, labels and answers out. It cuts every moment a player is on the ball in the main camera, plus every replay and highlight they appear in, labels each one, scores how worth watching it is, and finds it when you ask.

Between them sits one event stream with a published JSON Schema. The demo matches come from Regista's synthetic match generator, which writes the same stream.

The agent workflow

A Microsoft Agent Framework workflow: each agent has one job, hands typed state to the next, retries on failure, and routes what it cannot handle to a dead-letter file instead of crashing the run.

  1. Ingest reads the event stream and indexes it.
  2. Validator checks every record against the schema.Possession finds each player's time on the ball. in parallel, then joined
  3. Clip cuts on-ball moments, replays and highlights.
  4. Label names each moment, scores it and says why.
  5. Review asks a person about the labels it is unsure of.
  6. Persist stores clips and labels.
  7. Indexer adds them to the search index. only where Azure AI Search is configured
  8. Librarian answers questions over the labelled clips.
