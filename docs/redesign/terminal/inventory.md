# Scout terminal port: inventory of today's /scout and the terminal's data needs

Branch `ux/terminal`, cut from `main` with part A merged (1900d8a). No code was changed for this inventory. Every claim
below was read from the files named, and the API response shapes were checked on a local, offline TestClient run
(`REGISTA_DOTENV=`, nothing sent to Azure or the live app).

Two parts:

- **Part 1 (SC-xx):** everything today's `/scout` does. That covers `src/regista/static/scout/*`, the shared pieces it
  loads, the tests that read these files, and the constraints those tests set on the port. The port must keep all of it.
- **Part 2 (TD-xx):** each piece of data the sandbox terminal uses
  (`.claude/worktrees/sandbox-ref/sandbox/terminal.js`, fed by `terminal.json` from `tools/export_terminal.py`), mapped
  to the app's API or marked **MISSING** / **PARTIAL**.
