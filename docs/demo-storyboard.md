# Regista demo video: storyboard (target 1:55, hard limit 2:00)

Everything on screen is rendered from synthetic data by this repo. No real footage, no real players. Record at 1280x720 or higher; the renderer's output is 1280x720 at 25 fps.

Assets to prepare before recording (all from the Quickstart in the README):

| Asset | Command |
|---|---|
| Full broadcast `syn_0294.mp4` with end card | `python3 -m regista.render data/synthetic/sample/syn_0294 --out docs/demo/syn_0294.mp4` |
| Clip reel for Castellanos (9) | `python3 -m regista.render.clips data/synthetic/sample/syn_0294 --player t_home_09 --out docs/demo/clips_t_home_09` |
| Viewer running | `uvicorn regista.api:app` then open `http://localhost:8000` (screen-record the browser) |
| Terminal for the Librarian and agents | `python3 -m regista.librarian …`, `python3 -m regista.agents …` (large font, dark theme) |
| Realism report | `docs/realism-report.md` rendered in a markdown viewer |

Production notes:

- Record the terminal beats first; they are deterministic. Record the viewer beat last so the cache has the clips rendered (open each clip once before recording).
- Do not use music with a licence you cannot show. The rules forbid third-party copyrighted material in the video.
- The Azure beat is live: record it against the Container Apps URL in `.env` (`REGISTA_APP_URL`). Upload a freshly generated match each take, since a repeated match id returns 409. Only name Fabric, AI Search, or Azure MCP Server if they are wired by recording day.
- Keep the final cut under 2:00 including the end card. Judges may stop at 2:00.
