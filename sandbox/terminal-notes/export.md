# B6 data export: sandbox/terminal.json

Synthetic data: invented players and clubs in the Regista League, generated by Regista.

**What it is.** `sandbox/tools/export_terminal.py` builds `sandbox/terminal.json` from part A's engine directly
(`regista.season.metrics.load_metrics`, `regista.season.profiles.load_season`, the fixtures' event streams), not over HTTP.
The terminal's screens read only this file.

    PYTHONPATH=/Users/zaid/Desktop/Regista/src REGISTA_DOTENV= python3 sandbox/tools/export_terminal.py [--app URL] [--out FILE]

It runs in about 2 s once the league's match folders exist (it builds them on first run, like the app).

**Size: 7.58 MB** (minified). 127 metrics, 108 league players (102 played), 6 clubs, 30 matches.

**What is in it.**
- The metric catalogue: key, label, group, definition, rule, sources (titles and links in `sources`), unit, kind, per90 and
  ratio flags, higher_is_better (null for style markers), positions, digits, noisy flag and split-half r, qualifying
  minutes, and for ratios the minimum attempts with the rule. 74 of 127 metrics are marked noisy, as the engine marks them.
- Every league player, public bio only (name, club, position, role, kit number, age, height, foot, nationality), minutes,
  appearances, and every metric's value, count (or numerator and denominator), percentile and qualified flag.
- Evidence per metric: **capped at 10 items per metric per player** (the engine API's own default), in match order, with
  the true total. Items point by index into the player's `moments` (match, round, opponent, time, minute, clip id, video
  url). Physical metrics' evidence is one value per match.
- Shots in the attacking frame (x toward the goal at x = 105), with xG, outcome, body part, minute and clip; the touch
  heat-map grid (12 x 8, the profile page's); form per match for every metric and consistency for the position's default
  columns; 5 similar players; team style per club with ranks and per-match values; the league table.
- `"app": "http://localhost:8040"`: clip videos play from the local app on part A's code (`app + video_url`). The live app
  still runs the old league, so never point clips at it.

**Checks.**
- The script asserts no hidden rating key (league.json `attributes` and every name in `league.RATINGS`, `GK_RATINGS`,
  `PHYSICAL`) appears anywhere in the output, walking every key and then the JSON text.
- Femi Toure's 127 metrics (value, percentile, count, numerator, denominator, evidence totals and the first 10 items'
  match, clip and value) match `GET /api/players/pl_bro_09/metrics` on the local app exactly. He is the top scorer (3).
- A clip from the export (`/api/matches/rl_r01_eas_bro/clips/cl_t_away_09_000002.mp4`) plays from the local app (200,
  video/mp4).
- Nothing reached Azure or the live app; `.env` was never loaded.
